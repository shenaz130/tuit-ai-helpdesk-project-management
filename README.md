# TuIT — AI Smart IT Help Desk

### AI Project Management | Risk Management | Responsible AI Governance

**Academic Project | Master of Artificial Intelligence | Seneca Polytechnic**

## Project Overview

TuIT is a fictional AI-powered IT help desk proposed for Seneca staff as part of the MAI104 AI Project Management course. The proposed system would answer routine IT questions using approved knowledge-base articles and escalate unresolved issues to human IT operators with conversation context.

This repository presents the project management and governance work developed for a planned sandbox MVP. It does not represent a deployed or operational AI chatbot.

## Project Scope

- **Methodology:** Hybrid Agile
- **Duration:** 10 weeks across five two-week sprints
- **Work breakdown:** 30 work packages
- **Planned effort:** 400 task hours
- **Project management platform:** Monday.com
- **Environment:** Proposed sandbox MVP using synthetic data
